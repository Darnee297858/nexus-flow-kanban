# 📋 NexusFlow Kanban

An intuitive, interactive, and responsive Kanban task management application built with React, Vite, and Tailwind CSS. Designed to streamline workflow productivity with drag-and-drop task tracking, status column management, and local persistence.

---

## ✨ Features

- 📌 **Visual Workflow Management:** Organize tasks seamlessly across customization status columns (e.g., *To Do*, *In Progress*, *Review*, *Done*).
- ⚡ **Dynamic Task Operations:** Easily create, edit, move, and delete tasks in real time.
- 🎨 **Modern & Clean UI:** Responsive layout with smooth micro-interactions powered by Tailwind CSS.
- 🏷️ **Tags & Priority Badges:** Categorize tasks with priority indicators and custom tags.
- 💾 **Persistent Data:** Keep track of your task state across sessions.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel
